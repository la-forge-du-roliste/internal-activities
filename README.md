# Internal Activities — Foundry VTT V14

Petit module pour Foundry VTT V14 et D&D5e 5.2–5.3.

Il permet de marquer une activité comme interne :

- elle disparaît de la boîte de choix de l'objet ;
- elle reste visible dans l'onglet Activités pour le MJ ;
- elle reste exécutable par SC – More Activities, Midi-QOL et les macros.

## Installation manuelle

Le chemin final doit être exactement :

`Data/modules/internal-activities/module.json`

Attention à ne pas obtenir un dossier imbriqué du type :

`Data/modules/internal-activities-v1.1.0-v14/internal-activities/module.json`

Après copie, redémarrer complètement Foundry VTT.

## Utilisation

Dans l'onglet Activités d'un objet D&D5e, cliquer sur l'icône en forme d'œil placée dans les contrôles de l'activité.
