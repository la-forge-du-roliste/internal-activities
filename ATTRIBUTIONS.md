# Third-Party Resources and Attributions

Internal Activities currently distributes no third-party images, illustrations, fonts, textures, sounds, video, or other multimedia assets.

The eye symbols used by the interface reference Font Awesome CSS classes already provided by the Foundry Virtual Tabletop environment. This module does not include or redistribute Font Awesome font or icon files.

Every future third-party resource must document its file, source, author, license, license link, modifications, and redistribution terms. A resource must not be added unless its origin and redistribution rights are clear.
